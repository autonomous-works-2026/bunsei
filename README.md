# 文整

日本語のMarkdownや文章を、ブラウザ内だけで点検・整形する小さなツールです。入力内容はサーバーへ送信されません。

## 使い方

1. `index.html` を最新のブラウザで開きます。
2. 文章またはMarkdownを貼り付けます。
3. **点検する**で確認項目を表示します。**安全に整形**は、行末空白・改行形式・過剰な空行だけを変更します。

## 点検項目

- 行末の空白
- 3行以上続く空行
- 和文・欧文の句読点スタイルの混在
- 全角・半角英数字の混在
- 120文字を超える行
- 代替テキストが空のMarkdown画像

## 性質と制限

- インストール、アカウント、外部API、広告、トラッキングは不要です。
- 点検結果は補助であり、文章の正しさ・アクセシビリティ・著作権上の適合を保証しません。
- 表記を勝手に置換しないよう、整形の変更範囲を意図的に狭くしています。
- 対応ブラウザは、ES Modules、Clipboard API、CSS `color-mix()` を実装する現行ブラウザです。

## 開発・検証

依存関係はありません。Node.jsがある場合は、次のコマンドで中核ロジックを検証できます。

```sh
node --test *.test.js
```

ソースはGitHubで公開しています。公開後の変更も、入力内容を外部送信しないという設計を維持します。
